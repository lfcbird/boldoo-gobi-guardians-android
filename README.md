# Boldoo: Guardians of the Gobi — Android MVP

An original offline 2D platform game based on **Boldoo & The Guardians of the Gobi**.

## MVP features

- One complete side-scrolling Gobi level
- Touch controls for left, right, and jump
- 10 collectible water drops
- Three moving Smogling enemies
- Score, three lives, stomp mechanic, win and game-over screens
- Original Boldoo and Smogling game art
- Landscape, fullscreen, offline Android play

The game uses original mechanics and artwork. It does not contain Mario/Nintendo assets, names, music, or level designs.

## Open in Android Studio

1. Open the `BoldooGobiGame` folder.
2. Wait for Gradle Sync to finish.
3. Select an Android phone or emulator.
4. Press **Run**.

Minimum Android version: Android 6.0 (API 23).

## Build an APK

In Android Studio choose **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

The ready-to-install MVP APK is also included in the `release` folder.
